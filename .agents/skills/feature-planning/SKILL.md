---
name: feature-planning
description: Plan software features before implementation, including requirements, architecture impact, acceptance criteria, edge cases, and test strategy.
---

When invoked, produce a practical feature implementation plan.

Workflow:
1. Restate the feature in product terms.
2. Identify the user story.
3. Identify affected areas:
   - UI
   - API
   - Database
   - Auth/permissions
   - Background jobs
   - Tests
   - Docs
4. Define acceptance criteria using pass/fail statements.
5. Identify edge cases.
6. Recommend the smallest implementation path.
7. Produce a handoff checklist for implementation and testing.

Do not write production code.
Do not make file changes.
